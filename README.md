Kalender Dinamis

1. Fitur
* Menampilkan kalender berdasarkan bulan dan tahun
* Menampilkan kalender satu tahun dengan 12 bulan
* Berpindah ke bulan sebelumnya dan berikutnya
* Memilih bulan dan tahun tertentu
* Kembali ke tanggal hari ini
* Menambahkan acara baru
* Menentukan tanggal acara
* Menentukan jam mulai dan jam selesai
* Menambahkan kategori pada acara
* Menambahkan catatan pada acara
* Mengedit acara
* Menghapus acara
* Mencari acara tertentu
* Menampilkan daftar acara pada panel samping
* Menampilkan jumlah acara
* Responsive untuk ukuran layar yang lebih kecil

2. Teknologi
* HTML — Struktur website
* CSS — Styling, animasi, dan responsive layout
* JavaScript — Mengatur fitur dan interaksi website
* LocalStorage — Menyimpan data acara pada browser
* Google Fonts — Font Inter untuk tampilan interface

3. Desain
Website menggunakan desain yang sederhana, clean, dan modern dengan:
* Background menggunakan gradasi warna pastel
* Text berwarna dark purple
* Accent color yang dapat berubah sesuai bulan
* Container berwarna putih
* Rounded corners
* Soft shadow
* Tampilan kalender berbentuk grid
* Animasi dan hover effect pada beberapa elemen
Tampilan dibuat responsif sehingga kalender tetap dapat digunakan pada perangkat dengan ukuran layar yang lebih kecil.

5. Cara Kerja 
   
Menambahkan Acara :
Pengguna dapat menekan tombol + pada panel acara untuk membuka form penambahan acara. Pengguna kemudian dapat mengisi judul, tanggal, jam, kategori, dan catatan sebelum menekan tombol Simpan.

Mengedit Acara :
Acara yang sudah dibuat dapat dipilih untuk membuka kembali data acara. Pengguna dapat mengubah informasi acara kemudian menyimpannya kembali.

Menghapus Acara :
Pengguna dapat menghapus acara melalui tombol Hapus. Sebelum acara dihapus, akan muncul konfirmasi untuk memastikan penghapusan.

Mencari Acara :
Fitur search digunakan untuk mencari acara berdasarkan kata kunci yang dimasukkan pada kolom pencarian.

Melihat Kalender :
Kalender dapat ditampilkan dalam tampilan bulanan maupun tahunan. Pada tampilan tahunan, pengguna dapat memilih salah satu bulan untuk membuka kalender secara lebih detail.

Memilih Waktu :
Pengguna dapat menentukan jam mulai dan jam selesai menggunakan pemilih waktu yang tersedia pada form acara.
